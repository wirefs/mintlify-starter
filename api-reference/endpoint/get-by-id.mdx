---
title: "GET /api/properties/{id}/ — Retrieve a Property by ID"
sidebarTitle: "Get by ID"
description: "Fetch a single property record by its Ask Wire integer ID. Returns the full Property object including all fields, or 404 if the ID does not exist."
---

Use this endpoint when you already know a property's Ask Wire `id` and want to retrieve its complete record in a single call. If you only have the source platform's identifier (e.g. a portal listing number), use [Get by Reference ID](/api-reference/endpoint/get-by-reference-id) instead. To discover IDs through search, use [List Properties](/api-reference/endpoint/get).

All requests require a valid Bearer token in the `Authorization` header.

---

## Path parameter

<ParamField path="id" type="integer" required>
  The unique Ask Wire integer ID of the property to retrieve.
</ParamField>

---

## Example request

```bash
curl -X GET "https://pandora.ask-wire.com/api/properties/1/" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

---

## Response

Returns a single Property object on success (`200 OK`). Returns `404 Not Found` if no property exists with the given ID.

### Core fields

<ResponseField name="id" type="integer">
  Unique Ask Wire property ID.
</ResponseField>

<ResponseField name="reference_id" type="string">
  The source platform's own identifier for this property.
</ResponseField>

<ResponseField name="polymorphic_type" type="string">
  Property type: `listing` or `foreclosure`.
</ResponseField>

<ResponseField name="listing_type" type="string">
  For listings: `sale`, `rent`, or `sold`.
</ResponseField>

<ResponseField name="country" type="string">
  Country where the property is located, e.g. `greece` or `cyprus`.
</ResponseField>

<ResponseField name="address" type="string">
  Full address string as provided by the source.
</ResponseField>

<ResponseField name="url" type="string">
  Direct URL to the property listing on its source platform.
</ResponseField>

<ResponseField name="description" type="string">
  Property description as provided by the source.
</ResponseField>

<ResponseField name="images" type="string">
  URL to the property's primary image.
</ResponseField>

<ResponseField name="source" type="string">
  Source platform name, e.g. `spitogatos`, `xe`.
</ResponseField>

<ResponseField name="source_type" type="string">
  Source category, e.g. `broker`, `owner`.
</ResponseField>

<ResponseField name="tags" type="array">
  List of tag IDs associated with the property.
</ResponseField>

</ResponseField>

<ResponseField name="parent_code" type="string">
  Code of the parent geographic unit.
</ResponseField>

<ResponseField name="parent_id" type="integer">
  ID of the parent geographic unit.
</ResponseField>

<ResponseField name="level" type="integer">
  Level in the Ask Wire geographic hierarchy.
</ResponseField>

<ResponseField name="country" type="string">
  Country this unit belongs to.
</ResponseField>

<ResponseField name="created_at" type="datetime">
  When this geographic record was created.
</ResponseField>

<ResponseField name="modified_at" type="datetime">
  When this geographic record was last modified.
</ResponseField>
