The Ask Wire API gives you programmatic access to real estate property listings, foreclosures, geographic data, and location intelligence across Greece and Cyprus. All responses are returned as JSON, and the API is split across two base URLs depending on what you need to do: authenticate first against the Auth service, then query data through the Properties API.

## Base URLs

The API uses two separate base URLs:

| Service | Base URL |
|---|---|
| **Properties API** | `https://pandora.ask-wire.com` |
| **Auth API** | `https://zeus.ask-wire.com` |

All property, geographic, and enrichment endpoints are served from `https://pandora.ask-wire.com`. Authentication endpoints are served from `https://zeus.ask-wire.com`.

## Authentication

Every request to the Properties API must include a valid Bearer JWT token in the `Authorization` header:

```
Authorization: Bearer <your_token>
```

You obtain a token by posting your credentials to `POST /auth/otp/login` on the Auth API. Tokens are valid for **24 hours**, after which you must request a new one.

<Warning>
  Never expose your token in client-side code or public repositories. Treat it with the same care as a password.
</Warning>

## Response Format

All endpoints return JSON. Paginated list endpoints wrap their data in a standard envelope:

| Field | Type | Description |
|---|---|---|
| `count` | integer | Total number of records matching the query |
| `next` | string \| null | URL of the next page, or `null` if you are on the last page |
| `previous` | string \| null | URL of the previous page, or `null` if you are on the first page |
| `results` | array | The records for the current page |

**Example paginated response:**

```json
{
  "count": 342,
  "next": "https://pandora.ask-wire.com/api/properties/?page=3",
  "previous": "https://pandora.ask-wire.com/api/properties/?page=1",
  "results": [...]
}
```
